北京交通大学VPN使用指南
作者：系统管理员
发布日期：2022-12-21
北京交通大学
VPN
使用指南
SSL VPN (Security Socket Layer Virtual Private Network)
指的是基于安全套接层
(SSL)
协议建立的远程安全访问通道的
VPN
技术。利用
VPN
技术，身处校外的用户通过互联网建立的虚拟专用通道接入到校园网内，使他们可以像校内其他计算机用户一样，访问校园网内所有开放的网络资源。
一、使用
VPN
的条件
用户使用
VPN
的两个条件：一是用户已经接入互联网；二是具有校园网上网账号和密码。
需要注意的是，如果用户只访问校外站点或资源，或者用户只访问交大校园网那些已对外开放的资源时（如交大主页及院级主页、
MIS
系统等），则无需使用
VPN
。
如果用户需要访问交大校园网内那些未对外开放的网络资源和图书馆国内外电子资源库时，在接入互联网的基础上，还要通过用户计算机上的浏览器利用
HTTPS
协议建立与校园网
SSL VPN
设备之间的虚拟专用通道。在传输的过程中，用户的所有数据包都是加密在
Internet
上传输的，用户感觉就像是在用交大校园网内部的一台计算机一样，只不过速度没有在学校内部那么快。
截止
2014
年
10
月，交大
SSL VPN
支持的操作系统包括
Windows XP
、
Windows Vista
、
Windows 7
、
Windows 8
以及
MacOS
等操作系统，兼容
IE11
及以下各版本的浏览器，支持
IE
浏览器、火狐浏览器。
二、
SSL VPN
使用方法介绍
1.
用户连入互联网后，打开
IE
浏览器（注意：为保证各类资源的可访问性，请使用
IE
浏览器或者火狐浏览器），通过
HTTPS
协议输入校园网
SSL VPN
网址
https://vpn.bjtu.edu.cn
，以建立
VPN
虚拟专用通道，显示如下的登录页面。
2.
用户输入自己的校园网计费系统的用户名和密码，认证通过后出现如下欢迎页面。
并且右下角任务栏出现
图标（图标为红色代表
VPN
虚拟专用通道已经建立，灰色代表通道尚未建立），这时，用户计算机就和
SSL VPN
设备建立了
VPN
虚拟专用通道，可重新打开新的浏览器窗口，输入要访问的校园网内网址，用户可以像在校园网内用户一样访问校园网资源。
3.
如果用户是第一次登录
SSL VPN
，那么登录成功后，系统会安装
SSL VPN
插件（只需安装一次），用户只要按照安装提示进行操作即可。
插件安装完成后，如果右下角任务栏没有出现
图标，请在页面启动，点击欢迎页面中“
Network
”
TAB
页，如下图所示：
然后点击“开始
VPN
客户端”按钮，启动
VPN
。
右下角任务栏出现
图标，
VPN
通道建立完成。插件安装成功后，再次访问
VPN
系统，无需进行上述插件安装过程，登陆后，会自动启动安装完成的插件。如需卸载该插件，可在欢迎页面中“
Network
”
TAB
页，点击“
Uninstall
”按钮。
4.
退出
VPN
系统：
SSL VPN
访问结束后，双击任务栏右边的红色
图标，按以下步骤退出
VPN
系统：
点击“
Disconnect
”按钮可以暂时中断
VPN
通道，但在欢迎页面还保留用户的登陆信息，可以在该页面再次启动
VPN
客户端。
三、注意：
1.
初次登录时，
VPN
系统将在你的计算机上安装相关插件，如果你的计算机有拦截软件或防火墙等，请选择“始终允许”来允许
VPN
插件的安装，或在安装
VPN
插件时关闭拦截软件或防火墙。另外，安装的速度可能比较慢，请大家耐心等待，因为系统需要下载“
SSL VPN
”的客户端（约
3M
），需要花费一定的时间（主要根据用户端的网速决定）。
2.
在使用
VPN
时，可能需要使用到浏览器的
ActiveX
以及
Cookie
等功能，如果在浏览器中禁用了
ActiveX
或者
Cookie
，都将导致无法登录。如果取消禁用后仍无法访问，请关闭或删除防火墙后再使用。
3.
由于校内资源及图书资源及办公资源都已经对校内用户开放，校内用户使用本系统会占用
VPN
的网络资源，因此校园网内用户不允许接入
VPN
设备。
